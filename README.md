# Banco de Dados

Repositório dedicado à organização de exercícios, consultas SQL e práticas desenvolvidas durante meus estudos de Banco de Dados na graduação em Engenharia de Software e Estudos Pessoais.

## Objetivo

Consolidar conhecimentos sobre bancos de dados relacionais, desenvolver habilidades com SQL e documentar minha evolução prática ao longo da graduação.

## Tecnologias

- **PostgreSQL** — consultas SQL e manipulação de dados.
- **MySQL** — estudos e exercícios práticos.

*As tecnologias serão adicionadas conforme o avanço dos estudos.*

## Organização

```text
Banco_de_Dados/
├── PostgreSQL/
│   └── Exercicio_01
├── MySQL/
└── README.md
```

Os exercícios são organizados por tecnologia e aula, facilitando a consulta e o acompanhamento dos conteúdos estudados.

## Conteúdos estudados

- Fundamentos de Banco de Dados
- Linguagem SQL
- Criação e manipulação de tabelas
- Consultas e filtros
- Relacionamentos entre tabelas
- Chaves primárias e estrangeiras
- Integridade e restrições de dados

*Esta seção será atualizada conforme novos conteúdos forem estudados.*
